# violinTopics

A simple web application for crowdsourcing violin topics that are of interest to adult violinists.

## Purpose

The application allows participants to suggest and vote on topics for violin workshops and community learning events.

## Technology

- HTML
- CSS
- JavaScript

## Possible future stack

- Cursor for AI-assisted development
- Next.js for a more structured web application
- Supabase for database and authentication
- Vercel for deployment

## Status

Early prototype.
